1、哪个 action 的平均 D1 最高？最低？
post的平均D1最高，view的平均D1最低

2、你对这个排序的一个解释假设（别下结论，用“可能”）
post 属于高投入、高主体性的行为，用户在完成一次主动创作后，更容易在次日继续回访；而 view 属于低投入的被动行为，用户完成一次浏览后缺乏继续回访的动机。

3、Day4 你准备怎么验证（比如：按 community+action 交叉 / 看 base 太小导致波动）
(1)检查不同 action 的 base users 是否存在样本量过小问题，排除由波动导致的假象
(2)在样本量可接受的前提下，进一步按 community × action 交叉拆分，判断高留存 action 是否在特定社区中更明显

4、为什么在 Day3 里，我们定义“returned users”为：第 t 天做过某个 action 的用户 ∩ 第 t+1 天所有活跃用户，而不是“第 t+1 天仍然做同一个 action 的用户”？

因为单一行为具有偶然性和低频性，如果将“是否再次执行同一行为”作为留存标准，会低估真实回访；因此在留存分析中，更合理的做法是将“是否在次日再次活跃（不限定行为）”作为留存判定，而将具体行为作为影响留存的解释变量。
