# 项目总览

## 执行摘要
本项目基于 Travel Stack Exchange 的真实公开用户行为数据，研究**社区规模、短期留存与参与深度**之间的关系。

项目使用了 **414,791 条真实行为记录**、**40,600 名用户**、以及 **214,923 条 user-day 记录**，时间范围覆盖 **2011–2024 年**。核心发现包括：

- **社区规模峰值与用户粘性峰值并不出现在同一时期**
- **回答型贡献行为的次日留存最高（约 42%）**
- 这一优势在**大样本、bootstrap 置信区间以及不同社区阶段比较**下仍然保持稳定

项目最终将社区质量问题解释为一个**参与深度问题**，而不仅仅是一个活动量问题。

---

## 1. 项目标题
**Travel Stack Exchange 社区留存与参与深度分析**

这是一个基于真实公开社区行为数据构建的分析项目，旨在研究 **活动规模、短期留存和参与深度** 如何随时间演化，并如何共同影响社区质量。

---

## 2. 核心业务问题
本项目主要回答四个问题：

1. 社区在不同时期的规模和活跃度如何变化？
2. 社区规模峰值是否与短期留存峰值重合？
3. 不同参与行为是否对应显著不同的留存结果？
4. 这些行为差异在社区不同发展阶段中是否仍然成立？

---

## 3. 数据概况
**数据来源：** Travel Stack Exchange 公开数据转储  
**时间范围：** 2011-06-21 到 2024-03-31

### 数据规模
- **414,791** 条真实社区行为
- **40,600** 名用户
- **214,923** 条 user-day 记录

### 核心行为类型
- `question`
- `answer`
- `comment`

---

## 4. 分析工作流程

### 阶段一：基于 Toy Data 的方法训练
项目首先使用 toy 数据集建立完整分析链条，并训练分析过程中的方法纪律。

**在这一阶段完成的内容包括：**
- D1 retention 计算
- action 维度比较
- 置信区间估计
- base size 敏感性检查
- cohort 比较
- 分层验证
- 行为迁移分析
- baseline 预测建模

**目的：**  
在切换到真实公开数据前，先建立严谨的分析框架和思维方式。

### 阶段二：迁移到真实社区数据
随后将完整工作流迁移到真实的 Travel Stack Exchange 数据上。

**主要步骤包括：**
1. 从 XML 原始文件构建事件流表
2. 构建 user-day 行为表
3. 计算 DAU 与 D1 retention
4. 分析月度活跃与留存结构
5. 按参与深度对行为进行分层
6. 用 base size、置信区间和阶段比较验证差异稳定性

---

## 5. 核心方法

### 5.1 User-Day 表构建
将原始行为日志聚合为 `user_id × event_date` 的结构，并统计每日：
- total events
- question count
- answer count
- comment count

这张表是后续所有留存和行为分析的基础。

### 5.2 核心指标
项目计算了以下关键指标：
- **DAU**
- **D1 retention**
- **MAU**
- **月均 DAU**
- **月均 D1 retention**

### 5.3 行为分层
为了更好表示参与深度，项目将 user-day 分为三类：
- `question_user_day`：当天至少有一次提问
- `answer_user_day`：当天至少有一次回答
- `comment_only_user_day`：当天只有评论，没有提问或回答

这三类行为被进一步解释为三种不同参与模式：
- **需求表达**
- **轻互动**
- **高价值贡献**

### 5.4 稳健性验证
为了避免对点估计过度解读，项目进一步加入了：
- base size 检查
- 日级波动分析
- bootstrap 置信区间
- 跨阶段比较

---

## 6. 核心发现

### 6.1 社区规模峰值与用户粘性峰值并不重合
月度活跃和月度留存并没有在同一时期达到峰值。

- **MAU 峰值：** 2019-05
- **月均 DAU 峰值：** 2016-08
- **月均 D1 retention 峰值：** 2011-06

**解释：**  
社区增长与用户粘性有关，但并不等价。

### 6.2 贡献型行为的留存最强
action-level 的 D1 retention 呈现清晰梯度：

- **answer_user_day：42.0%**
- **comment_only_user_day：26.5%**
- **question_user_day：22.6%**

**解释：**  
更深层次的内容贡献行为，与短期留存的相关性显著强于轻互动或需求驱动型行为。

### 6.3 差异在大样本和置信区间下仍保持稳定
留存差异在较大样本规模下仍然成立：

- **answer：58,509** 条 base user-day
- **comment-only：113,682** 条 base user-day
- **question：42,732** 条 base user-day

bootstrap 置信区间也较窄：

- **answer：** [41.6%, 42.5%]
- **comment-only：** [26.2%, 26.7%]
- **question：** [22.2%, 23.0%]

### 6.4 这一模式在不同社区阶段中仍然成立
项目将社区时间线分为三个阶段：
- **early stage：** 2011–2014
- **middle stage：** 2015–2019
- **late stage：** 2020–2024

在三个阶段中，`answer_user_day` 始终保持最高留存。

**解释：**  
这意味着核心发现不只是单一时期现象，而是一个跨阶段的结构性洞察。

---

## 7. 业务解释
如果将 Travel Stack Exchange 视为一个社区产品，本项目说明：

- 并不是所有活跃行为都具有相同的留存质量
- 贡献型行为与用户粘性的相关性，强于单纯的活跃量
- 增长团队需要区分：
  - 需求表达
  - 轻互动
  - 高价值贡献

### 核心结论
> 社区质量不能只用活动规模衡量，还应关注活动背后的参与深度与参与类型。

## 9. 局限性
本项目仍然是观察性分析，因此结论需要谨慎解释。

### 主要局限包括
- 公开数据中没有直接的 view/impression 日志
- 行为与留存之间是相关关系，不是因果关系
- 回答用户可能天然与提问用户在能力、意图或熟悉度上不同
- 阶段划分具有分析意义，但本质上仍是人为设定
