# Day6 – 行为效果的“异质性”与“噪音源”识别（stability + base）

## Day6 要回答的问题
不同 community 中，同一种 action 的 D1 留存是否稳定？
哪些 community×action 组合可能只是“小样本噪音”，不值得做运营动作？

## 方法
- 对每个 community×action，计算每天的 D1 留存序列（只保留 base>=5 的天）
- 用三类稳定性指标衡量波动：
  - std_d1（标准差）：波动强弱
  - iqr_d1（四分位距）：对极端值更稳健
  - base 规模（avg_base、days_base_lt10）：判断波动是否由小样本放大

## 结果：高波动候选（噪音源）
- food×like：std_d1=0.155，total_base=41，days_base_lt10=7/7
- tech×like：std_d1=0.151，total_base=36，days_base_lt10=6/6

解释（非因果）：
这些组合的 base 长期很小，留存比例对少数用户回访非常敏感，
因此“看起来波动大/表现好或差”很可能是统计噪音，而非真实机制差异。

## 结果：相对更可参考的组合
在满足 total_base>=80 且 n_days>=10 的组合中，主要由 view 行为构成。
这说明当前数据中“可用于稳定估计”的组合有限，后续需要针对核心场景补充更大样本或做定点验证。

## 运营含义（决策建议）
- 不建议把运营资源投入到“长期小 base + 高波动”的组合上，容易优化到垃圾互动
- 更合理的策略是：
  1) 先选择 base 相对充足且波动较小的社区作为实验场
  2) 在特定社区内设计引导（例如在 travel 社区引导 comment），并通过后续对照验证判断是否有效
