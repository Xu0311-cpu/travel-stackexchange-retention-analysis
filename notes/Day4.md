# Day4 – 验证「行为带来留存」是否为统计假象

## 问题背景
在 Day3 中，我发现 post 行为的平均 D1 留存率最高。但由于不同 action 的活跃用户规模差异较大，这一结论可能受到样本量（base size）和随机波动的影响。

因此，Day4 的目标是验证：
post 的高留存是否只是由于 base 较小而被放大，还是在更稳定的统计口径下仍然成立。

---

## Step 1：检查各 action 的 base size 分布
我首先统计了每种 action 在每日的 base 用户规模，包括：
- 平均 base
- 中位数 base
- 最小 / 最大 base
- base < 5、base < 10 的天数

### 观察
post 行为的 daily base 较小，导致 D1 留存对个体用户的回访高度敏感，日均留存率更容易被极端值放大

为直观验证 base size 差异，我绘制了各 action 的平均 daily base 柱状图。结果显示 post 的平均 base 显著低于其他行为，进一步支持了其日均留存易受波动影响的判断。

---

## Step 2：使用 aggregated D1 留存进行稳定性验证
为避免“日均值被极端值放大”，我将所有日期的 base 和 returned 用户进行汇总，计算 aggregated D1 retention。

### 观察
在 aggregated 口径下，post 行为的留存优势仍然存在，但与其他行为的差距明显缩小，说明其在日均口径下的优势部分来源于样本量偏小带来的波动放大。

---

## Step 3：下钻到 community × action
为了避免“行为脱离场景”的误判，我进一步拆分到 community × action 层级，观察哪些组合在 aggregated 口径下仍表现稳定。

### 观察
将 action 与 community 结合，可以避免将“行为效果”与“内容场景效果”混淆，从而减少伪因果结论。
---

## 当前结论（暂定）

综合 Day4 的多层验证结果可以认为：

post 行为在留存指标上表现较高，并非完全由统计假象造成，但其优势在日均口径下被小样本波动放大。在 aggregated D1 口径下，post 的留存仍略高于其他行为，但差距明显缩小，说明其效果更接近真实水平。

进一步下钻到 community × action 层级后发现，post 行为的留存优势主要集中在特定社区（如 travel、tech），而在其他社区中并不稳定，且部分组合存在样本量过小的问题。

因此，post 行为本身并不能被视为“提升留存的通用手段”，其效果更可能依赖于具体的内容场景与用户动机。

## Day5 将要验证的问题
基于 Day4 的结果，下一步需要回答的问题是：
